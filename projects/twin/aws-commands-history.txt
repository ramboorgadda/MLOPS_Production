ISSUES RESOLVED
==============================================================
1. CloudFront 504          -> Origin protocol was https-only, S3 website is HTTP-only. Fixed to http-only.
2. CORS missing headers    -> OPTIONS route pointed to Lambda instead of API GW native CORS. Deleted the route.
3. Wrong API URL in bundle -> Frontend was built with localhost:8000. Rebuilt with correct API GW URL.
4. S3 stale cache          -> index.html had no Cache-Control. Set to no-cache.
5. Lambda throttled to 0   -> ReservedConcurrentExecutions=0 (full block). Deleted the limit.
6. Bedrock rate exceeded   -> Upgraded model from nova-lite to nova-2-lite.
7. Bedrock access denied   -> Lambda IAM role missing Bedrock perms. Attached AmazonBedrockFullAccess.
8. Invalid message format  -> System prompt injected as user message (two consecutive user roles). Fixed to use system= parameter in converse().
9. Model ID wrong format   -> nova-2-lite-v1:0 needs on-demand, not supported. Switched to us.amazon.nova-*:0 inference profiles.
10. Data files missing     -> PowerShell Compress-Archive with * doesn't recurse. Rebuilt zip with Python zipfile (forward-slash paths).

PENDING: Daily Bedrock token quota exhausted on Nova Lite/Micro/Pro. Resets at midnight UTC.
